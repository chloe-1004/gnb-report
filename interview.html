영상 업로드 · 수정
시연 전·중·후 — 실제 흐름의 마찰 포인트 파악
1
업로드 전에 보통 어떤 걸 준비하세요? 스튜디오 들어오기 전에 따로 하는 작업이 있나요?
→ 스튜디오 밖에서 해결 중인 워크플로우 파악 (외부 툴 의존도 확인)
2
지금 하신 과정에서 "이 단계가 왜 여기 있지?" 싶었던 순간이 있었나요?
→ 직접 말 안 해도 되는 방식으로 UX 불일치 구간 자연스럽게 추출
3
업로드하다가 멈추거나 뒤로 돌아간 적 있으세요? 그때 어떤 상황이었나요?
→ 이탈·재시도 패턴 수집 — 어느 단계에서 실수/혼란이 생기는지 확인
4
수정할 때 가장 많이 바꾸는 항목이 뭐예요? 그게 바꾸기 쉬웠나요?
→ 자주 쓰는 기능의 접근성 평가
5
올리고 나서 "아, 이거 바꿔야 하는데" 싶었던 적 있으세요? 그때 어떻게 하셨어요?
→ 업로드 후 수정 플로우 사용성 및 임시방편 행동 파악
📊
댓글 관리 · 분석 데이터
시연 후 — 실제 활용 행동과 니즈 확인
1
데이터를 보고 나서 실제로 행동을 바꾼 적 있으세요? 어떤 수치를 주로 확인하세요?
→ 데이터 활용도 측정 — 보기만 하는지 vs 의사결정에 쓰는지
2
댓글 관리할 때 가장 귀찮은 게 뭐예요? 지금은 어떻게 해결하고 계세요?
→ 현재 워크어라운드 발굴 (귀찮음이 큰 곳 = 개선 우선순위)
3
이 데이터를 팀이나 다른 사람한테 공유해야 할 때 어떻게 하세요?
→ 데이터 내보내기/공유 니즈 파악 (미지원 기능 수요 확인)
4
지금 보이는 데이터 중에서 "이게 있으면 좋겠다"고 생각한 수치가 있나요?
→ 신규 지표 니즈 수집
💬
전반적 사용 패턴
마지막 — 멘탈모델과 대안 행동 파악
1
숏폼 스튜디오 말고 같이 쓰는 툴이 있나요? 왜 그 툴을 같이 쓰게 됐어요?
→ 스튜디오가 커버 못 하는 영역 파악
2
"이건 꼭 스튜디오에서 해야 해"인 것 vs "어쩔 수 없이 여기서 하는 것"을 나눠보면 어떻게 될까요?
→ 핵심 기능 vs 차선책으로 쓰이는 기능 구분
3
스튜디오가 내일 없어진다면 가장 아쉬운 기능이 뭐예요?
→ 핵심 가치 직접 확인 (긍정적 질문으로 방어 없이 답변 유도)
4
스튜디오 처음 쓸 때랑 지금이랑 다르게 쓰는 부분이 있나요?
→ 학습 곡선과 온보딩 문제 파악

⚡ 인터뷰어 가이드

시연 중 개입하지 말고, 막히는 구간이 생겨도 3~5초 기다렸다가 힌트
"왜 그렇게 하셨어요?" 보다 "지금 어떤 생각이셨어요?"가 더 많이 나옴
잘 된다고 긍정 반응 주면 이후 답변이 긍정 편향됨 — 중립 유지
"보통은요?" "항상 이렇게 하세요?" 로 예외 케이스 꼭 확인
